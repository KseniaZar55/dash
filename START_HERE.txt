CINÉ CLUB — БЫСТРЫЙ СТАРТ (OMDb API)

1. Установи Python 3.10+: https://www.python.org/downloads/
2. В этой папке открой файл .env в Блокноте.
3. Убедись, что строка OMDB_API_KEY= содержит твой OMDb API-ключ.
4. В этой папке открой CMD (адресная строка Проводника -> напиши cmd -> Enter).
5. Выполни по одной строке:
   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py -m uvicorn backend.main:app --reload
6. Открой http://127.0.0.1:8000

Важно: при первом открытии CINÉ CLUB загрузит каталог фильмов из OMDb. Это может занять до минуты и использует несколько десятков запросов. Каталог кешируется на 6 часов, чтобы беречь бесплатный лимит в 1 000 запросов в день. Не публикуй файл .env и не отправляй его другим людям.
Не закрывай окно CMD во время работы сайта.
